# Push to GitHub

1. **Create repository at:**
   https://github.com/new

   - Repository name: `perfume-store`
   - Description: "SAFARI Perfume Store - E-commerce website"
   - Public: Yes

2. **Then run these commands in your terminal:**

```bash
git remote add origin https://github.com/bilal-asim/perfume-store.git
git push -u origin master
```

That's it! Your code will be pushed to GitHub.
